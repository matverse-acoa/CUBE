# CUBE

> Interface geométrica e espaço de experiência do MatVerse.

O CUBE é a camada onde pessoas atravessam o organismo MatVerse por meio de Copilot, Cube e Kernel. Ele apresenta estados, faces, receipts e trajetórias; não substitui o Cassandra Control Plane nem concentra autoridade de decisão.

## Papel arquitetural

- **CUBE vê e apresenta.**
- **Cassandra interpreta e governa.**
- **Replit executa capabilities.**
- **Base44 amplia cognição sob contrato.**
- **MongoDB preserva memória operacional.**
- **Twin GPT-Φ preserva o modo local.**

A implementação inicial está em desenvolvimento na branch `bootstrap/cube-workspace-v0.1`.
